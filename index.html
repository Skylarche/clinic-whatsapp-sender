Automated Background Sending Guide

Upgrade from `wa.me` manual links to 100% automated API dispatching

Why Use Backend API?

The current browser version uses standard WhatsApp Web deep links (wa.me). To send PDFs automatically in the background directly from your Lab Information System (LIS), you can connect to the official WhatsApp Business Cloud API or Twilio for WhatsApp.

Option A: Official Meta WhatsApp Cloud API (Node.js Example)

Send approved message templates directly via HTTP Requests:

// Example Node.js / Express snippet for WhatsApp Business API
const axios = require('axios');

async function sendLabResultPDF(patientPhone, pdfUrl, patientName) {
  const url = `https://graph.facebook.com/v18.0/${process.env.WHATSAPP_PHONE_ID}/messages`;
  
  const payload = {
    messaging_product: "whatsapp",
    to: patientPhone, // International format without +
    type: "template",
    template: {
      name: "lab_result_notification",
      language: { code: "en_US" },
      components: [
        {
          type: "header",
          parameters: [{
            type: "document",
            document: {
              link: pdfUrl,
              filename: `${patientName}_Lab_Result.pdf`
            }
          }]
        },
        {
          type: "body",
          parameters: [
            { type: "text", text: patientName }
          ]
        }
      ]
    }
  };

  await axios.post(url, payload, {
    headers: { Authorization: `Bearer ${process.env.WHATSAPP_TOKEN}` }
  });
}

Key Steps to Set Up Full Automation:

  1. Register a Meta Developer account and set up a WhatsApp Business App.
  2. Submit your message templates (e.g., "Lab Report Ready") for Meta verification.
  3. Upload generated lab report PDFs to a secure Cloud Storage bucket (AWS S3, Google Cloud, etc.) to get a public signed URL.
  4. Call the backend API upon PDF generation to automatically notify patients instantly.
